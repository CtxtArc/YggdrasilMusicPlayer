# Yggdrasil

<p align="center">
  <b>A modern, lightweight Android music player focused on performance, organization, and a refined listening experience.</b>
</p>

<p align="center">
  Built with AndroidX Media3, Material Design 3, and a powerful local music library system.

---

## Overview

**Yggdrasil** is a modern Android music player designed for users who want greater control over their local music collection.

Unlike traditional music players that rely only on standard metadata, Yggdrasil provides advanced organization tools such as custom tagging, folder-based filtering, and flexible playlist management.

The application features a true dark OLED-friendly interface with a vibrant Catppuccin-inspired color palette while maintaining smooth performance and efficient playback.

---

## Features

### High-Performance Playback

- Powered by **AndroidX Media3 (ExoPlayer)** for reliable and efficient audio playback.
- Optimized for smooth local music playback.
- Persistent playback state restoration:
  - Current track position
  - Playback queue
  - Shuffle mode
  - Repeat mode

---

### True Dark Interface

Designed with OLED displays and modern Android design principles in mind.

Features:

- Deep black background optimized for OLED screens.
- Material Design 3 components.
- Catppuccin-inspired accent colors:
  - Vibrant Red
  - Vibrant Blue
  - Vibrant Green

---

### Advanced Library Organization

Yggdrasil extends beyond standard music metadata management.

#### Custom Tags

Create a personalized organization system:

- Add custom labels to tracks.
- Filter music instantly using custom tags.
- Organize tracks according to personal preferences.

Examples:

- Workout
- Chill
- Favorites
- Driving
- Study

---

### Folder-Based Filtering

Maintain complete control over your music library.

Features:

- Select specific folders to include.
- Exclude unwanted audio files.
- Keep your library structured according to your preferences.

---

### Playlist Management

Manage custom playlists with a flexible workflow.

Supported features:

- Create playlists.
- Rename playlists.
- Add and remove tracks.
- Reorder tracks using drag-and-drop.

---

### Smart Queue

Manage upcoming playback with an interactive queue system.

Features:

- View upcoming tracks.
- Play tracks next.
- Add tracks to the queue.
- Reorder queued songs.

---

### Search and Sorting

Quickly navigate large music collections.

Features:

- Real-time search.
- Alphabetical sorting.
- Date-added sorting.

## Technology Stack

| Component | Technology |
|-----------|------------|
| Language | Java |
| UI Framework | Android XML with Material Design 3 |
| Playback Engine | AndroidX Media3 (ExoPlayer) |
| Database | Room Persistence Library |
| Image Loading | Glide |
| Concurrency | Guava ListenableFuture and Background Executors |

## Requirements

- Android 13 (API level 33) or higher.
- Music and audio access permissions.
- Local audio files stored on the device.
